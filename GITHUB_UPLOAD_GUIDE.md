# GitHub Upload Guide

1. Go to https://github.com and sign in.
2. Click the **+** button, then **New repository**.
3. Repository name: `online-course-learning-platform-analysis`
4. Choose **Public** if you want others to view it; add a README only if you are not uploading the existing one.
5. Create repository.
6. Click **Add file → Upload files**.
7. Upload the contents of this project folder (files and folders; not the ZIP itself if you want the files browsable).
8. Click **Commit changes**.

## Optional: run it before uploading
```bash
pip install -r requirements.txt
streamlit run app.py
```

Never upload passwords, API keys, or private information.
